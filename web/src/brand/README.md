# Marke: HMR-Logo

Quelle: `assets/brand/hmr-logo-source.jpg` (1125×2000 JPEG, Kopie der vom Rechteinhaber gelieferten Datei; beide nicht in Git, bei Bedarf beim Rechteinhaber anfragen). Erzeugt mit
`uv run --with pillow --with fonttools --with brotli python web/scripts/brand_assets.py` aus dem Projektwurzelverzeichnis.
Das Skript schneidet die Buchstaben frei, setzt sie auf Tintenfarbe #111111 mit Transparenz und erzeugt alle PNG-Dateien dieses Ordners.
Die Schrift für das Open-Graph-Bild ist Inter (SIL OFL 1.1, siehe `web/src/fonts/OFL-Inter.txt`).
Das Logo-Zeichen ist Eigentum des Rechteinhabers (Raphael Stolpe, hamburgmobility.de) und ist nicht Teil der Lizenz für Code, Daten oder Texte des Projekts.
